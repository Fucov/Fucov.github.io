Abstract

Original Abstract Summary

OpenShell is an open agent runtime and reference architecture that places policy enforcement outside the autonomous agent. It combines an isolated execution sandbox with a gateway, supervisor, policy prover, controlled credential delivery, inference routing, audit and infrastructure-level enforcement so agents can use tools while remaining within explicit operational boundaries.

中文摘要

OpenShell 将自主 Agent 的执行、网络、凭据和模型访问从应用内约定变成运行时约束。Agent 在受限沙箱中工作，外部监督器和网关负责生命周期、身份与策略；策略证明器检查权限边界，推理路由与审计链则连接模型调用和企业基础设施。

Technical Analysis

Problem

长时间运行的 Agent 会调用 shell、浏览器、API、凭据和模型。仅依赖 system prompt 或 Agent 自身遵守规则，无法在提示注入、工具滥用或模型失控时提供可验证边界。

Method

把策略放在 Agent 进程之外，以 deny-by-default 的网络和文件边界、按需凭据、系统调用监控、策略验证和统一推理网关控制 Agent 能做什么，并记录状态与审计事件。

Architecture

Agent sandbox 运行 Claude Code、Codex、Copilot CLI 等 harness，默认无直接网络且非特权；supervisor 位于沙箱外执行策略；gateway 管理身份、生命周期、配置和凭据；policy prover 检查权限/网络规则；policy-aware inference router 统一模型访问。参考架构向上连接 Kubernetes/Linux/Windows 等环境，向下可结合 Vera CPU、Rubin 推理基础设施与 BlueField/Sentry 的带外监控。

Key Innovation

不是再造一个 Agent SDK，而是把 Agent 的工具执行、模型调用、机密信息、网络出口和审计统一成可部署的 runtime boundary，并让策略独立于 Agent 代码。

Experiments

官方材料给出平台级声明：Vera CPU 对比 x86 为 Agent harness/tool use 提供 2× 性能，BlueField-4/Sentry 最高增加 20% Agent capacity。未披露完整模型、Agent 轨迹、并发、基线配置、置信区间或独立复现实验，因此不将这些数字外推到 OpenShell 软件本身。

Editorial Assessment

Why It Matters

Agentic serving 的瓶颈正从 token 调度扩展到有状态工具执行。若 runtime 能统一隔离、凭据、推理路由和策略，它会成为 session lifecycle、模型网关与企业安全之间的新基础层。

Limitations

核心系统性能、策略验证开销、沙箱冷启动、长会话状态恢复和故障注入结果尚未公开；平台数字来自厂商，且硬件参考架构包含未来/新一代组件。生态合作名单不等于生产规模验证。

Related Work

01
Docker / Kubernetes isolation

共同点：进程、文件和网络隔离。核心区别：通用容器不理解 Agent 推理、工具权限与凭据生命周期。新增量：OpenShell 把模型路由、策略和 Agent 状态并入边界。

02
gVisor / Firecracker

共同点：减小不可信工作负载攻击面。核心区别：它们主要提供内核/微虚拟机隔离。新增量：OpenShell 增加 Agent 特定的外部监督、策略证明与按需机密投递。

03
OPA policy-as-code

共同点：将授权规则从应用逻辑中分离。核心区别：OPA 是通用决策引擎。新增量：OpenShell 将策略落到 Agent sandbox、出口网络和 inference gateway 的执行路径。

04
LLM model gateways

共同点：统一模型路由、认证与审计。核心区别：网关通常只覆盖模型 API。新增量：OpenShell 将网关和本地工具执行、凭据、文件/网络限制及硬件侧监控连成端到端控制面。
