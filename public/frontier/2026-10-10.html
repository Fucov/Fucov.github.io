Abstract

Original Abstract Summary

The v0.7.1 release extends FlashInfer across several model-specific serving paths. It adds quantized expert-parallel MoE for Rubin and Blackwell SM12x, a fused Kimi K3 speculative-verification kernel, cuDNN-backed linear-attention prefill, dual-cache sparse MLA for DeepSeek-V4.1, compact GLM53-NoPE KV rows, reusable MLA execution plans, and per-model NVFP4 recipes.

中文摘要

本版的主线不是单个通用算子，而是把新一代模型的结构特征下沉为可被服务框架调用的专用执行路径：MoE 权重布局可在 prefill/decode 精度间切换，投机验证融合卷积、Delta Attention 与归一化，稀疏 MLA 同时处理双缓存和紧凑 KV 行。

Technical Analysis

Problem

Rubin/Blackwell 上的量化 MoE、线性注意力、稀疏 MLA 与投机解码各有不同的数据布局和状态更新；若框架分别拼装 kernel，会产生额外访存、启动与集成开销，也难以安全捕获 CUDA Graph。

Method

以 CuTe DSL、cuDNN 与专用 fused kernels 实现 NVFP4/MXFP8 expert-parallel MoE、packed speculative verification、linear-attention prefill、dual-cache sparse MLA，并提供计划复用、auto backend 与模型级量化配置。

Architecture

Serving framework → model-specific FlashInfer API → plan/autotune → CUDA Graph-safe kernel path；MoE 路径以 prepared expert layout 支持 W4A16 decode / W4A4 prefill，并通过 NCCL-EP 或 NIXL-EP 交换；attention 路径分别维护 recurrent state 或 paged dual KV cache。

Key Innovation

把模型结构、低精度表示、通信后端和执行计划绑定到稳定 API，而不是只发布孤立 microkernel；同一权重布局可按阶段选择不同激活精度。

Experiments

官方 release 披露三组独立证据：DGX Spark、Qwen3.8-Flash-Next MoE layer、单 token、W4A16 vs Marlin；8×B300、vLLM、Kimi K3、6 draft tokens、并发 1–32；GLM53-NoPE 仅比较 KV row bytes。完整端到端模型、统一请求分布与能耗未披露。

Editorial Assessment

Why It Matters

FlashInfer 是 vLLM、SGLang 等推理栈的重要 kernel 层；新版把 Blackwell/Rubin、新型线性/稀疏 attention 与量化 EP MoE 的集成面统一，可能缩短新模型进入高性能服务的路径。

Limitations

大多数收益是特定模型、GPU 或单层结果；1.36× 为单 token MoE layer，1.8–3.3% 为完整投机路径吞吐，19.5% 只代表某种 KV 行布局。缺少 H100/A100 回归、统一端到端基准和独立复现。部分 API 有升级与实验性变更。

Related Work

01
TensorRT-LLM kernels

共同点：为 NVIDIA GPU 提供模型专用融合算子。核心区别：TensorRT-LLM 是完整运行时，FlashInfer 更偏可嵌入 kernel/API 层。新增量：v0.7.1 同时暴露 EP、稀疏 MLA、线性 attention 与计划复用。

02
DeepEP / NCCL-EP

共同点：优化 MoE token dispatch/combine。核心区别：通信库不负责 expert GEMM 与量化布局。新增量：量化 MoE layer 把通信后端与 compute path 在 CUDA Graph 中衔接。

03
FlashMLA / DeepSeek sparse MLA

共同点：面向 MLA 的高效 KV 与 attention。核心区别：v0.7.1 增加 DeepSeek-V4.1 双缓存和 SM12x 路径。新增量：primary/extra cache 可有独立 page size 与 top-k。

04
Marlin / low-bit MoE

共同点：低比特权重提升 GEMM 吞吐。核心区别：Marlin 是通用低比特 matmul 基线。新增量：准备一次的 expert layout 可支持 W4A16 decode 与 W4A4 prefill，并扩展到 EP。
