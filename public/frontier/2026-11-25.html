Abstract

Original Abstract Summary（英文概述，非原文）

Spade searches how to build and assign pipeline replicas for disaggregated serving in heterogeneous edge fleets. The planner prunes dominated candidates, estimates layer allocations analytically, and chooses replicas under a congestion-oriented placement objective.

中文摘要

先压缩设备组合表示并剪去被支配的候选，再按性能模型分层，最后联合选择 prefill 与 decode 副本，优化给定负载下的拥塞代价。

Technical Analysis

Problem

异构设备下，分设备、切层和选阶段相互依赖；分别优化容易使某个阶段成为排队瓶颈。

Method

在候选层面按支配关系剪枝，用仿射时间模型进行 water filling；整数化后修复显存和层数限制。

Architecture

设备性能测量 → 类型计数压缩 → 单副本角色与层切分 → 有界多维背包选择整组 PD 副本。

Key Innovation

利用可递推的候选支配规则，而不是每个设备排列都做一次昂贵分区；把分区与全局拥塞接起来。

Experiments

合成 30 设备、五硬件类的规划问题，以遗传搜索结合 DP 切分作对照；另用十设备类与穷举的候选集合核对剪枝。

Key Results · 作者报告

作者报告，30 设备合成场景找到模型内最优解用时 441 ms；遗传搜索约两小时且拥塞目标高 19.7%。这是规划器耗时和目标函数差距，不是生产 TTFT 加速。

Editorial Assessment

Why It Matters · 编辑分析

设备不均衡的 PD 部署可先在控制面快速筛选候选，再实测最有潜力的布局。

Limitations

分析依赖性能与拥塞模型及输入负载；合成规模结果不能代替物理集群的尾延迟。代码公开未核实。

Editor Note

如用于真实集群，先比较预测与实测跨节点 KV 传输成本及慢设备漂移，必要时重新标定。

Abstract

Original Abstract Summary（英文概述，非原文）

LEGOSpec provides a shared training setup for comparing draft-model components rather than entire recipes. The authors use these studies to design DFlux and reduce training overhead through lookahead scheduling, cost-aware worker assignment and asynchronous supervision transfers.

中文摘要

框架把上下文输入、骨干、提案和损失拆成可替换模块，支持复用目标模型监督。DFlux 是实验导出的折中配方；训练系统另以预看调度和异步监督数据流提高利用率。

Technical Analysis

Problem

草稿模型不同训练配方容易把组件差异和数据、配置的差异混在一起；等长请求也可能有不同的有效锚点负担。

Method

用统一训练器和 recipe adapter 支持可控替换。目标侧按长度前瞻打包，draft 侧按预估锚点负担分配 rank。

Architecture

target prefill 产生隐藏状态 → 在线传送或离线落盘 → 有界队列预取 → draft 训练；DFlux 用混合窗口/全局注意力、残差修正和分层监督。

Key Innovation

既能做匹配数据的组件消融，也让调度看到长度之外的监督布局；不是仅以更大 drafter 换接受率。

Experiments

主训练为 16×H800、1.4M 样本、6 epochs；评测基于 Qwen3-4B、Qwen3.6-35B-A3B、Gemma4-12B-it，使用温度 1、五随机种子。另有同配方 80K 对照。

Key Results · 作者报告

作者表 III：Qwen3-4B、SWE-bench 的 32K–64K 输入下，DFlux 平均接受长度 4.08，最强表内对照 DLite 3.03；这是接受长度，不等于端到端时延倍数。训练吞吐实验另以 SpecForge 为对照，不能合并归因。

Editorial Assessment

Why It Matters · 编辑分析

对训练基础设施，target hidden-state 供给和 draft rank 负载可以独立优化；对 serving，应该按上下文和并发选择 drafter。

Limitations

收益依模型、上下文和并发变化；匹配试验的规模小于主训练。arXiv v2 称代码和权重可用，补档未核实独立开源端点及首发时刻。

Editor Note

实际移植先测额外显存、接受长度与 verify 闲置，再决定是否值得启用复杂 proposer。

Related Work

同为草稿训练基础设施，也是系统对照；LEGOSpec 增加组件匹配实验和锚点感知调度。

02 · DFlash
