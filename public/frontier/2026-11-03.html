Abstract

Original Abstract Summary

The paper identifies a metastable failure mode in PD-disaggregated agent serving: a short surge expands session working sets, destroys prefix reuse, and keeps service degraded after arrivals normalize. Basin combines fixed session priorities, predicted peak-context reservations, idle-decode memory and load shedding.

中文摘要

长会话把缓存命中率与离开速率耦合起来：越慢的请求活得越久、上下文越大，越容易继续挤掉缓存。Basin 用会话峰值上下文预测和自适应预算阻断该正反馈。

Technical Analysis

Problem

突发结束后，为什么 Agent serving 仍可能长期低 goodput？

Method

流体模型刻画 population-cache feedback；Basin 进行固定优先级、峰值上下文预留、跨 P/D 内存扩展与过载削减。

Architecture

SGLang PD-disaggregated engine；真实 H200 1P3D；会话级 admission controller 与 KV capacity manager。

Key Innovation

把缓存失稳定义为系统亚稳态，并给出恢复所需负载下降尺度，而非只做单次命中率优化。

Experiments

SGLang；36 个模拟部署；真实 H200 1P3D；含长上下文 SWE-bench Pro surge。不同倍数来自不同基线，不合并。

Editorial Assessment

Why It Matters

Agent 工作负载具有持续会话状态，传统稳态容量规划会系统性高估可承载负载。

Limitations

代码未披露；预测误差、租户公平性和跨模型泛化需进一步验证。

Editor Note

当天最重要的服务论文；它把“缓存容量不足”提升为动态稳定性问题。

Abstract

Original Abstract Summary

Penelope observes that late tokens are more expensive to recompute because they attend over longer histories. It preserves shared prefixes and cached suffixes while evicting the beginning of the non-shared history, then recomputes only missing segments.

中文摘要

传统“保前缀、丢尾部”忽略了注意力重算成本随位置增长。Penelope 在共享前缀之后反向选择驱逐区间，并统一管理 GPU/CPU 缓存。

Technical Analysis

Problem

Agent 多轮历史中，按序列尾部驱逐导致最昂贵 token 被反复重算。

Method

位置感知驱逐 + segment recomputation + GPU–CPU unified cache。

Architecture

SGLang 实现；GPU-only 与 GPU–CPU 两级 KV 存储。

Key Innovation

把每个 KV 片段的重算代价而非只看复用概率纳入 eviction objective。

Experiments

3 种 Qwen3 模型尺寸、真实 Agent traces；与原生 SGLang 比较。摘要未披露具体 GPU。

Editorial Assessment

Why It Matters

Agent 多轮复用的缓存价值并非均匀，后缀的计算价值可高于中间历史。

Limitations

摘要未披露硬件与代码；保留后缀需要正确的分段重算支持。

Editor Note

概念简单但抓住了长期被 FIFO/尾部驱逐掩盖的非均匀重算成本。

Abstract

Original Abstract Summary

Scute expresses five PEFT methods in a common six-slot LoRA-like normal form. Load-time merging removes inactive costs, while a byte model predicts the remaining live computation. The system batches heterogeneous adapters on vLLM without lossy LoRA conversion.

中文摘要

现有 multi-LoRA serving 排斥其他 PEFT 方法。Scute 用统一代数形式和 kernel 路径实现同批次精确执行，避免转换带来的显存与精度损失。

Technical Analysis

Problem

如何在单 GPU 上批量服务非 LoRA PEFT adapter？

Method

六槽 normal form、load-time merge、batched LoRA kernel 扩展与零参数 byte model。

Architecture

Hugging Face PEFT checkpoints → Scute normalization → vLLM batched adapter kernel。

Key Innovation

不是把 adapter 近似转为 LoRA，而是证明多个 PEFT 方法可由统一执行核精确表达。

Experiments

RTX A6000；五类 PEFT；burst serving；精度误差不超过各 adapter effect 的 1.5%。

Editorial Assessment

Why It Matters

多租户定制模型服务终于不必把 LoRA 当作唯一部署格式。

Limitations

仅单 GPU A6000；“精确”仍以数值误差指标呈现；代码链接未在摘要页披露。

Editor Note

代数归一化与 runtime batching 结合紧密，工程落地价值高。

Abstract

Technical Analysis

Problem

Method

Architecture
